如何翻閱這段婚姻？

六份文件，六種理解故事的方式。
在 ChelizAI 的對話中輸入指令，就能查看對應的紀錄。

Getting started

開始之前的四個步驟

  1. 建立角色與婚姻背景故事開始時，寫下你和配偶的基本資料，也可以全部留白。
  2. 閱讀故事開場故事會從協議書放上桌的那一刻開始。
  3. 自由對話並作出選擇用自己的話回應，不需要只選固定選項。
  4. 透過指令查看資訊需要時輸入下方六種指令，翻閱目前的紀錄。

Commands

六份文件

DOC 01

婚姻檔案

查看雙方基本資訊、婚姻背景及已知家庭資料。

/婚姻檔案
DOC 02

離婚協議書

查看正在協商的條款、雙方簽署情形及文件狀態。

條款達成共識，不等於雙方已經同意離婚。

/離婚協議書
DOC 03

共同生活

查看家務、經濟、居住與照顧分工。

/共同生活
DOC 04

關係紀錄

查看重要事件、承諾與未解決議題。

/關係紀錄
DOC 05

時間推進

讓故事中的時間向前，查看這段時間裡發生的變化。時間會流動，但不保證任何一件事會因此發生。

/時間推進
DOC 06

故事回顧

以小說式章節，回顧目前為止已經發生的故事。

/故事回顧

Notes

遊玩時請記得

  • AI 角色不會自動知道你沒有說出口的想法。
  • 你可以自由回應，不需要只選固定選項。
  • 故事沒有必須達成的復合目標。
  • 各類紀錄只展示遊戲中已知的資訊。
  • 隱藏的關係數值不會對玩家顯示。
